# Google Play Listing — Pilot Draft

## App name

Futsal

## Short description

Book futsal venues, manage teams, competitions, and venue operations.

## Full description — English

Futsal brings venue availability, booking, venue operations, teams and competitions into one mobile experience.

Players can discover futsal venues, check available times, reserve slots, follow venue updates, manage teams, and view competition fixtures, results, standings, brackets and player statistics.

Venue owners can manage one venue from a mobile-first operating schedule, record manual bookings and blocks, promote empty capacity, publish venue updates, run competitions, review occupancy and booking-value analytics, and manage subscription status.

Futsal supports Dari, Pashto and English with RTL-aware navigation for Afghanistan-first use.

Availability is treated as live operational inventory. Booking confirmation is performed by the server so conflicting reservations cannot both be confirmed.
